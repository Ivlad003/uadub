# Словник наголосів для uadub.
# Почули в дубляжі неправильний наголос — допишіть слово з правильним наголосом
# і запустіть ту саму команду uadub ще раз (переозвучиться лише голос).
#
# Формати (по одному слову на рядок, можна кілька форм через пробіл):
#   замо́к          ← знак наголосу після голосної (на Mac: Option+E, потім голосна, або скопіюйте ́)
#   зам+ок         ← плюс перед наголошеною голосною
#   замОк          ← велика наголошена голосна
#   замок = замо́к  ← можна й так
#
# Слово береться в точно такій формі, як звучить у тексті (відмінок теж).
# Приклади (приберіть # щоб увімкнути):
# один+адцять
# кілом+етр
# черг+овий
