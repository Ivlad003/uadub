# CUDA port (Linux / Windows with NVIDIA) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make uadub run on Linux and Windows PCs with NVIDIA cards (8–24 GB) from one install command, with the same pipeline, prompts and voices as on the Mac.

**Architecture:** Each stage keeps its logic and gets a backend chosen by platform behind a small seam: `uadub/asr.py` (adapters `mlx`, `onnx` = Parakeet v3 via onnx-asr, `ctranslate` = faster-whisper), the existing `llm.LLM` seam with Ollama as the default off the Mac (model picked by VRAM), and `uadub/device.py` for the PyTorch engines. Packaging adds uv extras `cuda` / `cpu` with a pinned PyTorch CUDA index; `install.sh` / `install.ps1` and `uadub --doctor` carry the user through setup. Nothing in `translate`, `fit`, `mix`, `mux`, `parts` or `review` changes.

**Tech Stack:** Python 3.12, uv, PyTorch (CUDA 12.8 wheels), onnx-asr + onnxruntime(-gpu), faster-whisper (CTranslate2), Ollama, audio-separator, ffmpeg, pytest.

**Spec:** `docs/superpowers/specs/2026-10-21-cuda-port-design.md`

## Global Constraints

- Offline by default: every new backend runs locally; `--llm claude:…` stays the only cloud path and keeps printing its warning (spec §2, AGENTS.md rule 3).
- One heavy model resident at a time: stages stay in `spawn` subprocesses; no model loads at import time (AGENTS.md rule 2).
- Existing Mac caches survive: `asr_backend` enters the asr fingerprint only when it is not `mlx`; translate/tts/mix/mux fingerprints do not change in this plan (AGENTS.md rule 1, spec §4.1).
- No CUDA hardware in the loop: every code path must run on the Mac in CPU mode; the real CUDA run is one rented GPU hour (spec §2, §7).
- Console messages Ukrainian; code, comments, docs English; `README.uk.md` mirrors `README.md` (AGENTS.md rule 4).
- Unit tests in `tests/test_logic.py`, run with `.venv/bin/python -m pytest -q tests/test_logic.py`; they must pass before every commit and need no models.
- Model names: `nemo-parakeet-tdt-0.6b-v3` (onnx-asr), `large-v3-turbo` (faster-whisper), Ollama tags `gemma3:12b` (< 18 GB VRAM) and `gemma3:27b` (≥ 18 GB), to be confirmed against the Ollama library in Task 6.
- The PyTorch CUDA index is `https://download.pytorch.org/whl/cu128`, used only for `sys_platform == 'linux' or sys_platform == 'win32'`.
- Do not commit or push beyond what each task's commit step says; never touch `examples/`.

## Review Focus

Inputs the spec implies but no obvious test exercises; each line names the task that pins it with a test:

1. `nvidia-smi` prints two GPUs, or garbage, or is missing → VRAM detection takes the largest card, never crashes, and falls back to the small model (Task 6).
2. Ollama answers but the model is not pulled (HTTP 404), or the server is down (connection refused) → one Ukrainian message naming `ollama pull <model>` / `ollama serve`, no traceback (Task 6).
3. `--asr-backend onnx` where `onnx_asr` is not installed → a message naming the extra to install (`uadub[cpu]` / `uadub[cuda]`), not an ImportError traceback (Task 3).
4. onnx-asr token lists with a first token without a leading space, a last token (no next timestamp), and empty tokens → `tokens_to_sentences` still yields well-formed words and sentences (Task 3).
5. A Mac work folder opened on Linux (asr cached as `mlx`) → the asr stage reruns once because the fingerprint differs, instead of reading the old transcript as valid (Task 1).

```python
"""Speech recognition behind one seam: MLX on Apple Silicon, ONNX (Parakeet v3) and CTranslate2
(faster-whisper) everywhere else. Every adapter returns the same sentence dicts:
[{"start", "end", "text", "words": [{"w", "start", "end"}]}]."""

from __future__ import annotations

import importlib.util
from pathlib import Path

from .config import DEFAULT_ASR, WHISPER_ASR

BACKENDS = ("mlx", "onnx", "ctranslate")
ONNX_PARAKEET = "nemo-parakeet-tdt-0.6b-v3"  # onnx-asr model name (English and 24 more languages)
CT2_WHISPER = "large-v3-turbo"  # faster-whisper model name (other languages)


def has_mlx() -> bool:
    return all(importlib.util.find_spec(m) is not None for m in ("parakeet_mlx", "mlx_whisper"))


def choose_asr_backend(lang: str, *, platform: str, machine: str, has_mlx: bool, wanted: str = "auto") -> str:
    """auto → mlx on Apple Silicon with the MLX packages; else onnx (Parakeet) for English and
    ctranslate (Whisper) for every other language."""
    if wanted != "auto":
        if wanted not in BACKENDS:
            raise ValueError(f"невідомий ASR-бекенд «{wanted}»: {', '.join(BACKENDS)}")
        return wanted
    if platform == "darwin" and machine == "arm64" and has_mlx:
        return "mlx"
    return "onnx" if lang == "en" else "ctranslate"


def default_asr_model(backend: str, lang: str) -> str:
    if backend == "mlx":
        return DEFAULT_ASR if lang == "en" else WHISPER_ASR
    return ONNX_PARAKEET if backend == "onnx" else CT2_WHISPER
```

```python
# Typical Whisper hallucinations on silence/music (dropped when they come out of nowhere).
HALLUCINATIONS = ("시청해주셔서 감사합니다", "구독과 좋아요", "MBC 뉴스", "자막 제공", "다음 영상에서",
                  "thanks for watching", "subtitles by", "ご視聴ありがとうございました")


def whisper_words(segments: list[dict]) -> list[dict]:
    """Whisper segments (dicts with text, no_speech_prob, avg_logprob, words[word,start,end]) →
    timed words, without silent segments and the usual hallucinated sign-offs."""
    words: list[dict] = []
    for seg in segments:
        text = str(seg.get("text", "")).strip()
        if seg.get("no_speech_prob", 0) > 0.6 and seg.get("avg_logprob", 0) < -1.0:
            continue
        if any(h in text.lower() for h in HALLUCINATIONS) and len(text) < 40:
            continue
        for wd in seg.get("words", []):
            words.append({"w": str(wd["word"]).strip(), "start": float(wd["start"]), "end": float(wd["end"])})
    return words


def transcribe(wav: Path, *, lang: str, model: str, backend: str, total: float,
               device: str | None = None) -> list[dict]:
    """Timed sentences of `wav` (mono 16 kHz) with the chosen backend."""
    if backend == "mlx":
        return _mlx_sentences(wav, lang, model, total)
    if backend == "onnx":
        return _onnx_sentences(wav, lang, model, device)
    if backend == "ctranslate":
        return _ct2_sentences(wav, lang, model, device)
    raise ValueError(f"невідомий ASR-бекенд «{backend}»")


def transcribe_text(path: str | Path, *, backend: str, device: str | None = None) -> str:
    """Plain text of a short clip (the clone reference), in whatever language it is."""
    if backend == "mlx":
        from parakeet_mlx import from_pretrained

        return from_pretrained(DEFAULT_ASR).transcribe(str(path)).text.strip()
    sentences = transcribe(Path(path), lang="en", model=default_asr_model(backend, "en"), backend=backend,
                           total=0.0, device=device)
    return " ".join(s["text"] for s in sentences).strip()

def _mlx_sentences(wav: Path, lang: str, model: str, total: float) -> list[dict]:
```

```python
def tokens_to_sentences(tokens: list[str], timestamps: list[float], *, tail: float = 0.08) -> list[dict]:
    """onnx-asr gives SentencePiece tokens (a leading space starts a word) and one start time per
    token. A token ends where the next one starts; the last one gets `tail` seconds."""
    from .segments import merge_tokens_to_words, words_to_sentences

    toks = []
    for i, (text, start) in enumerate(zip(tokens, timestamps)):
        if not text:
            continue
        nxt = next((timestamps[j] for j in range(i + 1, len(timestamps)) if tokens[j]), None)
        end = float(nxt) if nxt is not None else float(start) + tail
        toks.append({"text": text, "start": round(float(start), 3), "end": round(end, 3)})
    if toks and not toks[0]["text"].startswith(" "):
        toks[0]["text"] = " " + toks[0]["text"]  # the first token starts the first word
    return words_to_sentences(merge_tokens_to_words(toks))


def _onnx_sentences(wav: Path, lang: str, model: str, device: str | None) -> list[dict]:
    _need("onnx_asr", "cpu")
    import onnx_asr
    import soundfile as sf

    from .device import ort_providers, pick

    waveform, sr = sf.read(str(wav), dtype="float32")
    if waveform.ndim > 1:
        waveform = waveform.mean(axis=1)
    m = onnx_asr.load_model(model, providers=ort_providers(pick(device))).with_timestamps()
    r = m.recognize(waveform, sample_rate=sr, language=lang if lang != "en" else None)
    return tokens_to_sentences(list(r.tokens or []), list(r.timestamps or []))
```

```python
def ct2_segments_to_dicts(segments) -> list[dict]:
    """faster-whisper Segment objects → the plain dicts `whisper_words` understands."""
    out = []

        out.append({"text": s.text, "no_speech_prob": s.no_speech_prob, "avg_logprob": s.avg_logprob,
```

```python
DEVICES = ("cuda", "mps", "cpu")


def choose(prefer: str | None, *, cuda: bool, mps: bool, env: str | None = None) -> str:
    """--device, then UADUB_DEVICE, then the best available accelerator."""
    wanted = prefer or env
    if wanted:
        if wanted not in DEVICES:
            raise ValueError(f"невідомий пристрій «{wanted}»: {', '.join(DEVICES)}")
        return wanted
    return "cuda" if cuda else "mps" if mps else "cpu"


def pick(prefer: str | None = None) -> str:
    import torch

    return choose(prefer, cuda=torch.cuda.is_available(), mps=torch.backends.mps.is_available(),
                  env=os.environ.get("UADUB_DEVICE"))
```

```python
def clipboard_command(platform: str, which=shutil.which) -> list[str] | None:
    """The command that reads stdin into the clipboard on this platform, or None."""
    if platform == "darwin" and which("pbcopy"):
        return ["pbcopy"]
    if platform == "win32" and which("clip"):
        return ["clip"]
    if which("wl-copy"):
        return ["wl-copy"]
    if which("xclip"):
        return ["xclip", "-selection", "clipboard"]
    return None


def copy_to_clipboard(text: str) -> bool:
    cmd = clipboard_command(sys.platform)
    if not cmd:
        return False
    try:
        subprocess.run(cmd, input=text.encode(), check=True)
        return True
    except Exception:
        return False


def editor_command(path: str, *, platform: str, env: dict, which=shutil.which) -> list[str] | None:
    """$VISUAL/$EDITOR (blocking, e.g. vim), else the OS text editor: open -t, notepad."""
    editor = env.get("VISUAL") or env.get("EDITOR")
    if editor:
        return shlex.split(editor, posix=platform != "win32") + [path]
    if platform == "darwin" and which("open"):
        return ["open", "-t", path]
    if platform == "win32" and which("notepad"):
        return ["notepad", path]
    return None


def open_in_editor(path: str | Path) -> None:
    p = str(Path(path).expanduser())
    cmd = editor_command(p, platform=sys.platform, env=dict(os.environ))
    if cmd:
        subprocess.run(cmd)
    else:
        print(f"   Відкрийте файл вручну: {p}")
```

```python
"""`uadub --doctor`: one pasteable report of the machine, the backends and what is missing."""

from __future__ import annotations

import importlib
import json
import shutil
import subprocess
import sys
import urllib.request
from pathlib import Path


def _version(module: str) -> str | None:
    try:
        return getattr(importlib.import_module(module), "__version__", "?")
    except Exception:
        return None


def collect(*, platform: str = sys.platform, machine: str | None = None, lang: str = "en") -> dict:
    import platform as _platform

    from . import __version__
    from .asr import choose_asr_backend, has_mlx
    from .config import CACHE_DIR, default_llm
    from .llm import detect_vram

    machine = machine or _platform.machine()
    info: dict = {"platform": platform, "machine": machine, "python": _platform.python_version(), "uadub": __version__,
                  "mlx": has_mlx(), "ffmpeg": shutil.which("ffmpeg"), "cache_dir": str(CACHE_DIR)}
    info["torch"] = _version("torch")
    try:
        import torch

        info["torch_cuda"] = bool(torch.cuda.is_available())
    except Exception:
        info["torch_cuda"] = False
    info["onnxruntime"] = _version("onnxruntime")
    try:
        import onnxruntime as ort

        info["ort_providers"] = ort.get_available_providers()
    except Exception:
        info["ort_providers"] = []
    info["ctranslate2"] = _version("ctranslate2")
    info["vram_gb"] = detect_vram()
    if shutil.which("nvidia-smi"):
        try:
            info["driver"] = subprocess.run(["nvidia-smi", "--query-gpu=driver_version", "--format=csv,noheader"],
                                            capture_output=True, text=True, timeout=10).stdout.strip().splitlines()[0]
        except Exception:
            info["driver"] = None
    info["asr_backend"] = choose_asr_backend(lang, platform=platform, machine=machine, has_mlx=info["mlx"])
    info["llm"] = default_llm(platform=platform, machine=machine, vram_gb=info["vram_gb"])
    if info["llm"].startswith("ollama:"):
        try:
            with urllib.request.urlopen("http://127.0.0.1:11434/api/tags", timeout=3) as r:
                info["ollama_up"] = True
                info["ollama_models"] = [m["name"] for m in json.loads(r.read()).get("models", [])]
        except Exception:
            info["ollama_up"], info["ollama_models"] = False, []
    try:
        info["cache_gb"] = round(sum(p.stat().st_size for p in Path(CACHE_DIR).rglob("*") if p.is_file()) / 1e9, 1)
    except Exception:
        info["cache_gb"] = 0.0
    return info


def render(info: dict) -> tuple[str, bool]:
    """The report text and whether everything required is in place."""
    lines, problems = [], []
    yes = lambda v: "так" if v else "ні"  # noqa: E731
    lines.append(f"uadub {info.get('uadub', '?')} · Python {info.get('python', '?')} · "
                 f"{info.get('platform', '?')} {info.get('machine', '?')}")
    if info.get("mlx"):
        lines.append("Рушій: MLX (Apple Silicon)")
    else:
        lines.append(f"torch: {info.get('torch') or 'немає'} · CUDA: {yes(info.get('torch_cuda'))}"
                     + (f" · драйвер {info['driver']}" if info.get("driver") else "")
                     + (f" · VRAM {info['vram_gb']} ГБ" if info.get("vram_gb") else ""))
        lines.append(f"onnxruntime: {info.get('onnxruntime') or 'немає'} ({', '.join(info.get('ort_providers') or []) or '—'})"
                     f" · ctranslate2: {info.get('ctranslate2') or 'немає'}")
        if info.get("torch") and not info.get("torch_cuda"):
            problems.append("CUDA недоступна для torch: перевірте драйвер NVIDIA (nvidia-smi) і що uadub встановлено з [cuda]")
        if info.get("asr_backend") == "onnx" and not info.get("onnxruntime"):
            problems.append("немає onnxruntime: uv tool install \"uadub[cuda]\"")
        if info.get("asr_backend") == "ctranslate" and not info.get("ctranslate2"):
            problems.append("немає faster-whisper/ctranslate2: uv tool install \"uadub[cuda]\"")
    lines.append(f"Розпізнавання: {info.get('asr_backend', '?')} · Переклад: {info.get('llm', '?')}")
    llm = str(info.get("llm", ""))
    if llm.startswith("ollama:"):
        model = llm.partition(":")[2]
        if info.get("ollama_up") is False:
            problems.append("Ollama не запущений: ollama serve (або встановіть з https://ollama.com)")
        elif info.get("ollama_up") and model not in (info.get("ollama_models") or []):
            problems.append(f"у Ollama немає моделі {model}: ollama pull {model}")
    if info.get("ffmpeg"):
        lines.append(f"ffmpeg: {info['ffmpeg']}")
    else:
        problems.append("немає ffmpeg: winget install ffmpeg (Windows) · sudo apt install ffmpeg (Linux) · brew install ffmpeg (macOS)")
    if info.get("cache_dir"):
        lines.append(f"Кеш моделей: {info['cache_dir']} ({info.get('cache_gb', 0)} ГБ)")
    if problems:
        lines.append("\nЩо виправити:")
        lines += [f"  ! {p}" for p in problems]
    else:
        lines.append("\nУсе на місці.")
    return "\n".join(lines), not problems
```
