# uadub — локальний AI-дубляж українською

[English](README.md) · **Українська**

Одна команда: на вході відео англійською (корейською, японською…), на виході те саме відео з
українською озвучкою. Оригінальна музика й фон зберігаються, додаються українські субтитри.
Усе працює **офлайн на Mac з Apple Silicon** (перевірено на MacBook Pro M1 Pro, 32 ГБ).

```bash
uadub lecture.mp4 --voice st          # → lecture.uk.mp4 + lecture.uk.srt
```

## Встановлення

```bash
brew install ffmpeg
git clone <цей репозиторій> ~/Documents/pet_project/uadub && cd ~/Documents/pet_project/uadub
uv venv --python 3.12 && uv pip install -e .
ln -sf "$PWD/.venv/bin/uadub" ~/.local/bin/uadub     # щоб `uadub` працював з будь-якої папки
uadub --prefetch --all                               # один раз завантажити всі моделі (~25 ГБ)
```

Після завантаження мережа більше не потрібна. Коли всі моделі в кеші, uadub сам вмикає
`HF_HUB_OFFLINE=1`. Потрібні Python 3.12, macOS 14+ і близько 25 ГБ місця під моделі.

## Швидкий старт

```bash
uadub video.mp4 --voice st                     # точні українські наголоси, без клонування
uadub video.mp4 --voice clone                  # голос оригінального мовця (наголоси можуть хибити)
uadub video.mp4 --voice st --emotion           # …з інтонацією оригінальних реплік
uadub video.mp4 --voice st --review            # пауза перед озвученням, щоб перевірити переклад
uadub drama.mkv --from ko --voice duo:st       # корейська дорама: чоловічі й жіночі репліки двома голосами
uadub --list-voices                            # усі доступні голоси
```

Результат — `video.uk.mp4` поруч з оригіналом:

- відеопотік копіюється без перекодування;
- звукова доріжка 1 — українська (за замовчуванням);
- доріжка 2 — оригінал (`--drop-original` її прибирає);
- українські субтитри вбудовані у відео, а також лежать окремим файлом `video.uk.srt`.

Аудіофайли теж підтримуються (результат `.m4a`).

Проміжні файли лежать у `video.uadub/` поруч із відео. Якщо повторити команду, готові етапи
пропускаються, а переробляється лише те, на що вплинули змінені параметри. Наприклад, після зміни
`--voice` репліки переозвучуються без повторного розпізнавання й перекладу.

## Вибір голосу

Є два типи голосів. Обирайте за тим, що важливіше для відео:

| | **Точні наголоси** — StyleTTS2-ukrainian | **Клонування** — OmniVoice |
|---|---|---|
| Параметр | `st`, `st:<ім'я>`, `duo:st` | `clone`, `clone:зразок.wav`, `"omni:<опис>"`, `duo` |
| Наголоси | кожне слово — за словником на 2,9 млн словоформ з урахуванням граматики; омографи розв'язує LLM; власні правки через `+` | іноді хибні: модель ігнорує знаки наголосу |
| Голоси | 31 український голос: 13 чоловічих, 17 жіночих, 1 дитячий | голос мовця з відео, ваш зразок або голос за текстовим описом |
| Швидкість на M1 Pro | ~0,2 с на секунду мовлення | ~1–1,5 с на секунду мовлення |
| Ліцензія | MIT | код Apache-2.0, ваги — некомерційні |

```bash
uadub video.mp4 --voice st                        # чоловічий голос StyleTTS2 за замовчуванням
uadub video.mp4 --voice "st:Марта Мольфар"         # будь-який з 31 голосу (можна початок імені: st:марта)
uadub video.mp4 --voice duo:st                    # чоловічий/жіночий для кожної репліки за висотою голосу
uadub video.mp4 --voice clone                     # кожна репліка голосом свого мовця
uadub video.mp4 --voice clone:announcer.wav       # ваш зразок на 5–15 с (український голос → без акценту)
uadub video.mp4 --voice "omni:female, young adult" --steps 32
uadub video.mp4 --voice duo                       # два голоси OmniVoice, чоловічий/жіночий для кожної репліки
```

### Інтонація оригіналу (`--emotion`)

Голоси StyleTTS2 читають рівно, як диктор. З `--emotion` кожна репліка зберігає тембр обраного
українського голосу, але бере інтонацію з оригінальної репліки: підйоми й спади, енергію, темп.
Це працює, бо StyleTTS2 зберігає тембр (*хто говорить*) і манеру мовлення (*як говорить*) окремо.
uadub бере манеру мовлення з голосу оригінальної репліки, вирізаного з відокремленої доріжки голосу.

```bash
uadub video.mp4 --voice st --emotion          # сила 0.8
uadub video.mp4 --voice st --emotion 1.0      # 0…1: більше = ближче до манери оригіналу
uadub drama.mkv --from ko --voice duo:st --emotion
```

На тестовому кліпі діапазон висоти голосу в озвучці зріс з 4,6 до 6,7 півтону (в оригінального
мовця — 6,9), розбірливість не змінилася. Репліки, які в оригіналі говорить людина іншої статі, ніж
обраний голос, озвучуються без перенесення інтонації: чоловічий голос із жіночою мелодикою звучить
неприродно. OmniVoice `clone` і так копіює інтонацію, тож прапорець потрібен лише для голосів `st`.

Є також швидкі, але роботизовані голоси `ukrainian-tts`: `dmytro` (за замовчуванням), `oleksa`,
`mykyta`, `tetiana`, `lada` і пара `duo:dmytro,tetiana`.

## Перевірка сценарію перед озвученням (`--review`)

`uadub video.mp4 --voice st --review` перекладає й розставляє наголоси, а потім **зупиняється**
перед озвученням. У терміналі з'являються:

- клікабельні шляхи до всіх файлів;
- правила редагування;
- готові команди для AI-агента.

У робочій папці лежать:

| Файл | Що це |
|---|---|
| `review.md` | сценарій: по блоку на кожну репліку |
| `en.srt` (або `ko.srt` …) | транскрипція оригіналу з таймінгами |
| `stress.txt` | словник наголосів цього відео |
| `AGENTS.md` | інструкція для Claude Code / opencode |

Блок у `review.md`:

```
## 0013  00:41.8–00:44.2 · чол. голос · слот 2.4 с · складів 12/13   ← не змінювати
EN:  There's two ways to download a model from this page.            ← не змінювати
UK:  Є два способи завантажити модель.                               ← переклад = субтитри
TTS:                                                                ← як читати; порожньо = як UK
НАГОЛОСИ: Є два сп+особи завант+ажити мод+ель.                      ← як наголосить StyleTTS2
```

Правте `UK:` і `TTS:` вручну або доручіть це агентові. Потім натисніть Enter у вікні uadub, і
озвучення продовжиться з урахуванням правок. Клавіші під час паузи:

| Клавіша | Дія |
|---|---|
| Enter | озвучити сценарій з правками |
| `o` | відкрити `review.md` у `$EDITOR` (або в стандартному редакторі) |
| `s` | відкрити `stress.txt` цього відео |
| `c` | скопіювати команду для Claude Code в буфер обміну |
| `q` | вийти; щоб продовжити, запустіть ту саму команду пізніше |

### Автоматична перевірка агентом (`--review-with`)

AI-агент може сам перевірити сценарій перед озвученням. Формат — `harness[:модель]`:

```bash
uadub video.mp4 --voice st --review-with claude                     # Claude Code, модель за замовчуванням
uadub video.mp4 --voice st --review-with claude:sonnet              # Claude Code з обраною моделлю
uadub video.mp4 --voice st --review-with opencode:anthropic/claude-sonnet-4-5   # opencode: провайдер/модель
uadub video.mp4 --voice st --review-with opencode:ollama/qwen3:8b   # повністю локально через Ollama
uadub video.mp4 --voice st --review-with codex:gpt-5                # Codex CLI
uadub video.mp4 --voice st --review-with gemini:gemini-2.5-pro      # Gemini CLI
uadub video.mp4 --voice st --review-with claude --review            # спершу агент, потім пауза для вас
```

- Без `--review` агент править сценарій, і одразу починається озвучення. З `--review` після нього
  буде звична пауза, щоб перевірити його правки.
- Агент може лише редагувати `review.md` і `stress.txt` у робочій папці та запускати `uadub --stress-lookup`.
- Повторний запуск тієї самої команди не повторює перевірку. Інший агент чи модель, новий переклад
  або `--redo review` запускають її знову.
- Будь-який інший інструмент — як власна команда: `--review-with "my-agent --flag {prompt}"`.
- Щоб агент працював завжди, задайте його один раз: `export UADUB_REVIEW_WITH=claude:sonnet`.

`AGENTS.md` підлаштовується під голос:

- для StyleTTS2 агент перевіряє кожен рядок `НАГОЛОСИ:` і виправляє хибні наголоси через `+`,
  а сумнівні слова звіряє зі словником командою `uadub --stress-lookup`;
- для OmniVoice агентові сказано не чіпати наголоси, бо позначки там додають акцент.

Правки зберігаються. Якщо пізніше змінити `review.md` чи `stress.txt` і повторити команду,
переробиться лише озвучення.

## Якість перекладу

Переклад робить локальна LLM (за замовчуванням Gemma 4 26B-A4B) за такими правилами:

- **Спершу зміст.** Перед перекладом модель читає стислий опис усього відео: тему, тон, хід думки.
  До кожного блоку вона також отримує фрагмент оригіналу навколо нього, близько 5000 символів.
  Перекладає за змістом, а не дослівно: перебудовує речення, змінює порядок слів, проговорює
  неявні зв'язки.
- **Помилки розпізнавання** в оригіналі («Quen 3.6» замість «Qwen 3.6») модель помічає й перекладає
  те, що насправді сказали.
- **Крилаті вирази й ідіоми** отримують українські відповідники, а не дослівний переклад.
  Наприклад: *a piece of cake* → «простіше простого», *break the ice* → «розтопити кригу»,
  *once in a blue moon* → «раз на сто років». Опис відео наперед збирає всі ідіоми, тож вони
  перекладаються послідовно.
- **Без англіцизмів.** Підписи інтерфейсу та звичайні терміни перекладаються («Використати цю модель»,
  «квантування»). Латиницею лишаються тільки власні назви. Окремий прохід знаходить слова, схожі на
  англійські, записані кирилицею, і переписує їх. Для фахової аудиторії див. `--domain` нижче.
- **Тривалість.** Кожна репліка має бюджет складів (в українській складів стільки, скільки голосних).
  Задовгі репліки скорочуються без втрати фактів.
- **Граматика.** Рід мовця (визначений за висотою голосу) задає «я зробив / я зробила». Глосарій
  тримає терміни однаковими по всьому відео. Свої терміни можна додати через `--glossary terms.txt`
  (рядки `English = Українська`).

### Фаховий переклад (`--domain`)

Бриф завжди визначає сферу відео (IT, медицина, фінанси, кулінарія…) і показує її рядком
`• сфера: …`. За замовчуванням переклад однаково лишається простою літературною українською для
всіх. З `--domain` він пишеться для фахівців цієї сфери:

- терміни такі, як їх справді кажуть українські фахівці, зокрема усталені англіцизми
  (*deploy* → «деплой», *pull request* → «пул-реквест», *framework* → «фреймворк»), а питомо
  українські там, де усталені саме вони («база даних»);
- назви кнопок, меню й налаштувань лишаються такими, як на екрані, латиницею в лапках
  (натисніть «Use this model»), а для озвучення записуються кирилицею;
- сленг і випадкові транслітерації звичайних слів («юзати», «дефолтний») однаково прибираються;
- правила перевірки (`review.md`, `AGENTS.md` для агента) переходять на той самий стиль.

```bash
uadub talk.mp4 --domain                 # сфера визначається автоматично
uadub talk.mp4 --domain "медицина"      # або вкажіть її самі, якщо визначилася неправильно
```

Ставте `--domain` без значення після назви файлу, а не одразу перед нею, інакше назву файлу буде
сприйнято як сферу. Увімкнення чи вимкнення прапорця перезапускає переклад (решта береться з кешу).
Ваш `--glossary` має пріоритет, і це допомагає у вузьких сферах.

### Довгі відео (`--part-minutes`)

Відео довше за 45 хвилин дубляжується частинами автоматично:

- аудіо розрізається в паузах на частини приблизно по 15 хвилин (спершу друкується план);
- спочатку розпізнається кожна частина, потім будується один бриф для всього відео, тож терміни,
  звертання і `--domain` скрізь однакові;
- превʼю кожної готової частини зʼявляється в `<назва>.uk.parts/NN.uk.mp4`;
- наприкінці частини склеюються в один `<назва>.uk.mp4` і `<назва>.uk.srt` поверх оригінального
  відео (без перекодування відео).

Памʼять не росте разом з довжиною відео. Якщо частина не вдалася, решта продовжують; запустіть ту
саму команду ще раз, щоб завершити. Якщо частина падає ще на розпізнаванні, запуск зупиняється до
спільного брифу (йому потрібні всі транскрипти); помилка зберігається в `state.json` робочої папки,
а повторний запуск продовжить. Щоб виправити одну частину, відредагуйте
`<назва>.uadub/parts/NN/review.md` (він зʼявляється після запуску з `--review` або `--review-with`)
і запустіть знову: переозвучиться лише ця частина, і результат склеїться наново. З `--review` пауза робиться для кожної частини; `q` зупиняє весь запуск.

```bash
uadub lecture.mp4                       # автоматично для відео понад 45 хв
uadub lecture.mp4 --part-minutes 8      # коротші частини для Mac з меншою памʼяттю
uadub lecture.mp4 --part-minutes 0      # ніколи не різати
uadub lecture.mp4 --keep-parts          # залишити превʼю частин
```

Робоча папка потребує близько 10 ГБ на 7 годин. `--subs` із частинами поки не працює: з `--subs` довге
відео обробляється цілим (`--subs` разом із явним `--part-minutes N` — помилка). Робоча папка
попереднього запуску цілим файлом (наприклад, розпочатого до появи частин) продовжується цілою;
щоб нарізати її на частини, додайте `--part-minutes 15`.

### Переклад через Claude, opencode, Codex чи Gemini (`--llm`)

За замовчуванням перекладає локальна Gemma. Натомість переклад можна віддати агентові, яким ви вже
користуєтеся, з тими самими промптами й правилами. Формат — `harness[:модель]`:

```bash
uadub video.mp4 --voice st --llm claude:sonnet
uadub video.mp4 --voice st --llm opencode:anthropic/claude-sonnet-4-5
uadub video.mp4 --voice st --llm codex:<модель>      # модель, доступна вашому акаунту Codex
uadub video.mp4 --voice st --llm gemini:gemini-2.5-pro
uadub video.mp4 --voice st --llm ollama:qwen3:30b    # локальний сервер Ollama, усе ще офлайн
```

- Текст відео надсилається цьому провайдеру, тож запуск уже не офлайновий. Розпізнавання мови
  й озвучення лишаються локальними. uadub про це попереджає.
- Використовується вхід або підписка самого CLI. Він працює без інтерфейсу, у порожній тимчасовій
  папці, без інструментів — лише як текстова модель.
- Кожен запит запускає CLI наново, це кілька секунд на виклик. Для 10-хвилинного відео виходить
  приблизно 10–20 викликів.
- Зміна `--llm` перекладає заново. Розпізнавання не повторюється.
- Щоб це було за замовчуванням: `export UADUB_LLM=claude:sonnet`.
- Поєднується з `--review-with`: наприклад, перекласти через `--llm claude:sonnet`, а перевірити
  через `--review-with opencode:<модель>`.

## Наголоси

- **StyleTTS2 (`--voice st…`)** наголошує кожне слово за словником
  [ukrainian-word-stress](https://github.com/lang-uk/ukrainian-word-stress): 2,9 млн словоформ
  зі «Словників України», граматичний контекст від Stanza. Омографи, які словник не розрізняє
  (за́мок/замо́к), LLM розв'язує за змістом речення. Тут `+` перед голосною (`зам+ок`) — справжній
  знак наголосу.
- **OmniVoice** ігнорує знаки наголосу ([#52](https://github.com/k2-fsa/OmniVoice/issues/52),
  [#65](https://github.com/k2-fsa/OmniVoice/issues/65)). uadub може примусово поставити наголос,
  переписавши слово транскрипцією ARPAbet (`[Z AA0 M AO1 K]`), але це додає англійський акцент.
  Тому транскрипція застосовується лише до справжніх омографів і слів, які ви додали самі.
- **Власні словники:**
  - `~/.config/uadub/stress.txt` — для всіх відео;
  - `video.uadub/stress.txt` — для одного відео;
  - формат: по слову в рядку (`кілом+етр` або `кіломе́тр`);
  - `~/.config/uadub/pronounce.txt` задає, як читати назви (`LM Studio = ел-ем студіо`).
- `--stress dict` вимикає автоматичну позначку омографів, а `--stress off` — усі позначки.

## Корейська, інші мови та субтитри

`--from ko` (а також `ja`, `zh`, `es`, `fr`, `de`, `it`, `pl`, `pt`, `tr`) перемикає розпізнавання
мови на Whisper large-v3-turbo й перекладає з цієї мови. Для корейської:

- імена передаються послідовно, за системою Концевича;
- звертання (오빠, 선배, 씨 …) звучать природно;
- репліки різних персонажів ніколи не зливаються в одну.

| Голос для дорам | Результат на тестовому діалозі |
|---|---|
| `--voice duo:st` | точні наголоси, чоловічий і жіночий голоси |
| `--voice duo` | природні голоси OmniVoice, чоловічий і жіночий |
| `--voice clone` | тембр акторів, але сильний корейський акцент — не рекомендовано |
| один голос + `--no-separate` | класичне закадрове озвучення одним голосом поверх приглушеного оригіналу |

Готові субтитри точніші за розпізнавання мови: `--subs drama.ko.srt` (або `.vtt`). Українські
субтитри можна просто озвучити: `--subs drama.uk.srt --subs-lang uk`.

## Усі параметри

| Параметр | Значення |
|---|---|
| `-o FILE` | файл результату (за замовчуванням `<назва>.uk.mp4`) |
| `--voice V` | голос, див. [Вибір голосу](#вибір-голосу) і `--list-voices` |
| `--emotion [K]` | голоси StyleTTS2 беруть інтонацію кожної репліки з оригіналу, K = 0…1 (без числа — 0.8) |
| `--steps N` | кроки якості OmniVoice: 16 (за замовчуванням, ~реальний час) або 32 (повільніше, чистіше) |
| `--from LANG` | мова відео (`en` за замовчуванням, `ko`, `ja`, …) |
| `--subs FILE`, `--subs-lang LANG` | готові субтитри замість розпізнавання |
| `--review` | пауза перед озвученням, щоб відредагувати сценарій |
| `--review-with HARNESS[:МОДЕЛЬ]` | автоматична перевірка агентом `claude`, `opencode`, `codex` чи `gemini` (модель — за бажанням) або власною командою |
| `--redo review` | ще раз перевірити агентом |
| `--glossary FILE` | ваш список термінів, `English = Українська` |
| `--domain [СФЕРА]` | фаховий переклад: термінологія сфери й усталені англіцизми, кнопки — як на екрані; сфера визначається автоматично, якщо не вказана |
| `--part-minutes N` | довге відео: частини ~N хв, розрізи в паузах (автоматично понад 45 хв; 0 — не різати) |
| `--keep-parts` | не видаляти превʼю частин після склеювання |
| `--gender male/female` | рід мовця для граматики (інакше — за голосом або визначається автоматично) |
| `--stress auto/dict/off`, `--stress-dict FILE` | режим наголосів, додатковий словник наголосів |
| `--no-separate` | лишити оригінальний звук приглушеним під голосом (закадровий стиль) |
| `--fast` | швидше відокремлення фону (htdemucs) |
| `--max-speed X` | максимальне прискорення репліки (1.25) |
| `--duck DB` | рівень фону під час мовлення (−4 дБ; −13 дБ з `--no-separate`) |
| `--text` | також зберегти транскрипцію оригіналу й переклад як `.txt` поруч із відео (`<назва>.en.txt`, `<назва>.uk.txt`, обидва поруч у `<назва>.en-uk.txt`, з наголосами в `<назва>.uk.stress.txt`); посилання з'являються в кінці |
| `--drop-original` | не зберігати оригінальну звукову доріжку |
| `--llm M` | модель перекладу: інша MLX-модель, `ollama:<модель>` або агент `claude[:модель]`, `opencode[:провайдер/модель]`, `codex[:модель]`, `gemini[:модель]` (не офлайн); за замовчуванням — з `UADUB_LLM` |
| `--redo STAGE`, `--stop-after STAGE` | примусово переробити етап / зупинитися після нього |
| `--workdir DIR` | куди класти проміжні файли (за замовчуванням `<назва>.uadub/` поруч із відео) |
| `--stress-lookup СЛОВО…` | показати варіанти наголосу слова зі словника з граматичними ознаками й запис із вашого `stress.txt` |
| `--prefetch [--all]`, `--list-voices` | завантажити моделі; показати голоси |

## Як це працює

```
відео ─ffmpeg→ аудіо ─BS-RoFormer→ голос + фон
   голос ─Parakeet v3 / Whisper (MLX)→ транскрипція з таймінгами ─прив'язка до мовлення, висота → рід мовця
      ─Gemma 4 (MLX): опис → переклад за змістом з контекстом → англіцизми → наголоси омографів
      ─[--review: ви / Claude Code / opencode правите review.md]
      ─StyleTTS2 / OmniVoice / ukrainian-tts → репліки під таймінг оригіналу
фон + голос (приглушення, вирівнювання гучності, лімітер) ─ffmpeg→ video.uk.mp4 + .srt
```

| Етап | Модель / інструмент |
|---|---|
| Відокремлення фону | `audio-separator`: BS-RoFormer (htdemucs з `--fast`) |
| Розпізнавання мови | `parakeet-mlx` (англійська), `mlx-whisper` large-v3-turbo (інші мови) |
| Переклад | `mlx-lm` з `gemma-4-26b-a4b-it-4bit` (або будь-яка MLX / Ollama модель) |
| Голос | StyleTTS2-ukrainian · OmniVoice · ukrainian-tts |
| Наголоси | `ukrainian-word-stress` + Stanza, LLM для омографів, `ipa-uk` для StyleTTS2 |
| Таймінг | бюджет складів, керування швидкістю / тривалістю TTS, Rubber Band (pedalboard) як запасний варіант |

Кожен важкий етап працює в окремому процесі, тож у пам'яті одночасно лише одна модель
(пік ~15 ГБ — для LLM).

Ідеї, запозичені з інших проєктів:

- VideoLingo: опис відео, переклад частинами з контекстом, прохід скорочення;
- open-dubbing: репліка може заходити в наступну паузу, прискорення обмежене;
- pyVideoTrans / VoiceStudio: бюджет довжини до синтезу;
- OmniVoice: генерування точної тривалості замість розтягування.

## Швидкодія та якість

На M1 Pro, 32 ГБ:

| Етап | Час |
|---|---|
| Відокремлення фону, BS-RoFormer / htdemucs | ~1× / ~0,4× реального часу |
| Розпізнавання мови, Parakeet / Whisper | ~0,1× / ~0,3× реального часу |
| Переклад (Gemma 4 26B, усі проходи) | ~1,5–2 хв на хвилину відео |
| Голос, StyleTTS2 / OmniVoice (16 кроків) / ukrainian-tts | ~0,2× / ~1× / ~0,4× реального часу |

Десятихвилинне відео обробляється приблизно за 30–40 хвилин від початку до кінця.

Якість перевірено зворотним розпізнаванням: озвучену доріжку транскрибували й порівнювали зі
сценарієм. Частка помилкових слів — 0,07–0,14, і більшість «помилок» — це числа, які розпізнавач
записав цифрами. Усі 31 голос StyleTTS2 розпізналися без жодної помилки на тестовому реченні.

## Обмеження

- Клонування OmniVoice переносить в українську акцент оригіналу (англійський, корейський). Для
  чистої української беріть `--voice st` або клонуйте український зразок.
- Ваги OmniVoice — некомерційні. Перш ніж монетизувати контент, перевірте ліцензію кожної моделі.
- Рід мовця визначається за висотою голосу, тож діти, крик чи шепіт можуть його збити. Визначений
  рід видно в `review.md`.
- Одночасне мовлення кількох людей і спів обробляються погано. Синхронізації губ і розділення на
  багатьох мовців (поки) немає.
- Пошкоджену аудіодоріжку (биті пакети AAC) uadub не відкидає, а відновлює. Зіпсовані місця стають
  тишею, не зсувають синхронізацію з відео й не перекладаються. Скільки секунд втрачено, видно в консолі.

## Структура проєкту

```
uadub/cli.py        CLI, етапи в окремих процесах, кеш стану, пауза --review
uadub/stages.py     extract → separate → asr → translate → tts → mix → mux
uadub/translate.py  промпти: опис, переклад за змістом, скорочення, англіцизми, омографи
uadub/tts.py        рушії StyleTTS2, OmniVoice і ukrainian-tts
uadub/stress.py     словники наголосів, омографи, ARPAbet для OmniVoice
uadub/review.py     експорт/імпорт review.md і AGENTS.md, запуск агента
uadub/textnorm.py   склади, числа → слова, вимова назв, латиниця → кирилиця
uadub/segments.py   речення, часові слоти, прив'язка до мовлення
uadub/fit.py        розміщення реплік на шкалі часу
uadub/subs.py       читання .srt / .vtt
uadub/term.py       клікабельні посилання в терміналі, буфер обміну, редактор
tests/              юніт-тести, генератори прикладів (EN/KO), перевірки якості (roundtrip, pace)
```
